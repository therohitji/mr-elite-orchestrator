```yaml
async def enrich_atom(atom):
```

```yaml
def evaluate_atom(atom, fetched_context):
    
    # 1. HARD CHECKS (Resources/State)
    if not fetched_context["resource_found"]:
        atom.status = "FAILED"
        atom.error_msg = "Required template not found."
        return atom # STOP HERE

    # 2. SOFT CHECKS (Policy Audit)
    # Only run if policies were actually found
    if fetched_context["policies"]:
        verdict = llm_judge.audit(
            action=atom.description,
            rules=fetched_context["policies"]
        )
        
        if verdict.is_violation:
            # 3. THE AUTONOMY DECISION (Escalate vs Block)
            if atom.risk_level == "HIGH":
                atom.status = "ESCALATED_TO_HUMAN" # Pause for Human
                atom.blocker_reason = verdict.explanation
            else:
                atom.status = "FLAGGED" # Proceed with warning
                atom.tags.append("policy_warning")

    # 4. DEFAULT PASS
    if atom.status == "PENDING":
        atom.status = "APPROVED"
        
    return atom
```

### **1. The Core Logic: The "Traffic Light" Algorithm**

The system decides the fate of an Atom using a **Decision Matrix**. It combines two inputs: **Violation Severity** (from Policy) and **Operational Risk** (from the Atom).

**The Algorithm (Decision Matrix):**

| **Violation Found?** | **Atom Risk Level** | **Traffic Light** | **Action** |
| --- | --- | --- | --- |
| **No** | Low / High | 🟢 **GREEN** | **APPROVE:** Move to Control Layer. |
| **Yes (Soft)** | Low (Drafting) | 🟢 **GREEN (Flagged)** | **WARN:** Proceed, but add a warning tag. |
| **Yes (Soft)** | High (Sending) | 🟡 **YELLOW** | **ESCALATE:** Pause. Ask Human for override. |
| **Yes (Hard)** | Any | 🔴 **RED** | **BLOCK:** Kill the Atom. Trigger Re-planning. |
- **Hard Violation:** Something physically impossible (Missing File, Closed Budget).
- **Soft Violation:** Something logically discouraged (Budget exceeded, Policy mismatch).

### **2. How "Checking" is Done (The Comparison Mechanics)**

We use a **Hybrid Comparison Engine**. We do not use LLMs for everything (too slow/expensive). We split the work.

### **A. The "Hard Check" (Deterministic Code)**

- **Method:** Simple Python `if` statements.
- **Comparison Logic:**
    - *Resource:* `if atom.context["resource_content"] is None` $\to$ **FAIL**.

### **B. The "Soft Analysis" (LLM-as-a-Judge)**

- **What it checks:** Nuance. (Is this "professional"? Is this "too expensive"?).
- **Method:** **LLM Semantic Comparison**.
- **Comparison Logic:**
    - We do not compare strings strictly (`"hire" == "hire"`).
    - We ask the LLM: *"Does Action X violate Policy Y?"*
    - **Input:** Atom Description + Retrieved Policy Text.
    - **Output:** `Violation: True/False` + `Severity: Hard/Soft`.

```yaml
JUDGE_PROMPT = """
You are the Policy Auditor. Compare the Action against the Rules.
Action: {action}
Policies Found: {policies}

TASK:
1. Does the action violate any policy?
2. If yes, is it a "Hard" violation (Illegal/Impossible) or "Soft" (Discouraged)?

OUTPUT JSON:
{
  "violation": bool,
  "severity": "hard" | "soft" | "none",
  "explanation": "string"
}
"""

def analyze_policy_compliance(atom):
    # If no policies were found during scanning, pass.
    if not atom.context.get("policies"):
        return LogicVerdict(status="pass", reason="No relevant policies found")

    # Call LLM
    result = llm.invoke(JUDGE_PROMPT, action=atom.description, policies=atom.context["policies"])

    if not result.violation:
        return LogicVerdict(status="pass", reason="Compliant")
    
    # Map Severity to Status
    if result.severity == "hard":
        return LogicVerdict(status="block", reason=result.explanation)
    else:
        # Soft violation - checking Risk to decide Yellow vs Green
        if atom.risk_level == "HIGH":
            return LogicVerdict(status="review", reason=result.explanation) # Yellow
        else:
            return LogicVerdict(status="warn", reason=result.explanation)   # Green (Flagged)
```
